---
name: Bloom visual direction
description: Durable visual preference for Bloom's shared application theme.
---

Bloom's shared visual language uses a very light blush-white page background, white card surfaces, gentle pink accents, rounded UI, and Poppins for both body and heading typography.

**Why:** This matches the original Bloom reference aesthetic: calm, warm, soft, and polished while remaining readable.

**How to apply:** Prefer existing theme tokens and shared components over page-specific palette changes. Keep the background near-white with a subtle pink tint, and use Poppins rather than introducing a second display font.
